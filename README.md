# Telegram бот заявок на C#

Бот на **C#/.NET 8** для приёма заявок с пошаговой формой, хранением в SQLite и разделением на активные/завершённые.

## Что умеет

- Главное меню:
  - `Активные заявки`
  - `Завершенные заявки`
  - `Оставить заявку`
- Пошаговая форма:
  1. Тип: `КТ` / `СТ`
  2. Позывной
  3. Время суток: `День` / `Ночь`
  4. Частота управления: `500` / `900` / `2400`
  5. Частота видео: `5.8` / `3.3` / `1.2`
  6. BIND-фраза
  7. Примечание (опционально)
- Хранение заявок в SQLite
- Просмотр активных и завершённых заявок в удобном карточном формате
- Завершение заявки командой `/complete <id>` только для Telegram ID из `CLOSER_IDS`

## Запуск

```bash
dotnet restore
dotnet run
```

Перед запуском задайте переменные окружения:

```bash
export BOT_TOKEN="<token>"
export CLOSER_IDS="123456789,987654321"
# необязательно
export DB_PATH="applications.db"
```

## Переменные окружения

- `BOT_TOKEN` — токен Telegram-бота (обязателен)
- `CLOSER_IDS` — Telegram ID, которым разрешено завершать заявки
- `DB_PATH` — путь к sqlite-файлу (по умолчанию `applications.db`)
