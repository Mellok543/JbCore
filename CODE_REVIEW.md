# Разбор предоставленного кода Telegram-бота

## Что уже сделано хорошо

- Логика разделена по сущностям: `BotApp`, `SessionState`, `Keyboards`, `ApplicationStore`, модели Telegram API.
- Есть валидация шагов анкеты в `SessionState`.
- SQL/Excel слой изолирован в `ApplicationStore`.
- Для Telegram polling уже реализован offset (`_offset = update.UpdateId + 1`), что предотвращает повторную обработку апдейтов.

## Критичные проблемы

1. **Секрет (BotToken) захардкожен в коде**
   - В `AppSettings.Default` токен записан прямо в исходник. Это риск компрометации бота.
   - Рекомендация: хранить токен только в переменных окружения (`BOT_TOKEN`) или secret storage.

2. **Несоответствие статусов заявок**
   - При создании заявки пишется статус `"Активна"`.
   - В выборке активных заявок используется фильтр `"active"`.
   - При завершении сравнивается `"active"`, а при завершении пишется `"Завершена"`.
   - В карточке завершение показывается только если `Status == "completed"`.
   - Из-за этого активные/завершённые заявки будут работать некорректно.

3. **Команда `/complete` почти всегда не сможет завершить заявку**
   - Метод `CompleteApplication` ищет заявку со статусом `"active"`, но при создании записывается `"Активна"`.

## Логические и UX-замечания

- Проверки вида `if (text == "Активные заявки") return "Недопустимый выбор";` дублируются во многих шагах. Лучше вынести в единый guard-метод.
- В `callsign/pilot_number/...` есть блокировка некоторых текстов, но нет блокировки `/start` как значения поля (кроме общей обработки в `BotApp`).
- Для даты используется `DateTime.Now.ToString("s")`; при разных часовых поясах лучше рассмотреть UTC (`DateTime.UtcNow`) и локализацию на выводе.
- `_sessions` хранится в памяти — после рестарта бота незавершённые анкеты теряются (возможно, это допустимо).

## Что сделать в первую очередь

1. Перенести `BotToken` в окружение и **немедленно перевыпустить текущий токен**.
2. Ввести единые константы статусов, например:
   - `const string StatusActive = "active";`
   - `const string StatusCompleted = "completed";`
   и использовать их во всех методах (`Add`, `Get`, `Complete`, `FormatCard`).
3. Добавить минимальные автотесты на:
   - создание заявки,
   - выборку активных,
   - завершение заявки,
   - выборку завершённых.
